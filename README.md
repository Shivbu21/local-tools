# Local Tools

Six free digital tools for local businesses. No commission, no subscription.

- **VoiceQ** (`voice/`) — AI voice receptionist: answers calls, books appointments, logs conversations
- **DukaanQ** (`dukaan/`) — WhatsApp storefront with UPI checkout
- **BillQ** (`bill/`) — recurring billing for milk, tiffin, subscriptions
- **RingQ** (`ring/`) — missed-call to WhatsApp auto-responder
- **CardQ** (`card/`) — smart digital business card
- **StockQ** (`stock/`) — low-stock alerts for kirana shops

All standalone static apps. Data stays on the device (localStorage). Open `index.html` or deploy the folder as-is.
